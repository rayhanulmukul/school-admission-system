# AI usage

AI assistance was used to implement the project from the supplied assignment: scaffolding the ASP.NET Core API and React interface, adding persistence and seat-hold workflows, configuring Docker Compose, writing PostgreSQL-backed API and concurrency tests, and drafting project documentation.

The API tests cover class creation and availability, seat hold and confirmation, duplicate/full-seat conflicts, ownership, cancellation, expiration, and concurrent requests. The implementation was locally validated with the test and build commands in the README. Authentication, payment processing, and production deployment configuration remain outside the assignment API contract.
